## FAQ

### What does VideoPatch do exactly?

VideoPatch modifies the installed video editor software to unlock premium features like watermark removal, high-quality export, and access to paid plugins and effects without requiring a subscription.

### Is VideoPatch safe to use?

Yes, VideoPatch is designed to be a safe, standalone utility. It does not contain any tool, adware, or unwanted software. Always download it from the official GitHub repository.

### Which video editors are supported?

VideoPatch currently supports CapCut (desktop), DaVinci Resolve (free version), Filmora, VideoPad, HitFilm (free version), and Movavi Video Editor.

### Will I get software updates?

VideoPatch does not interfere with the normal update process of your video editor. However, a major software update may reset the patch, requiring you to run VideoPatch again.

### Is this legal?

VideoPatch is provided for educational and research purposes only. Using it to compatibility software licensing may violate the terms of service of the respective software. The user assumes all responsibility.

### My anticomponent flagged the file. What should I do?

Some security software may flag patching tools as a potential risk (PUP/Heuristic). You can add an exception for the file after verifying you downloaded it from the legitimate source.

### Do I need to keep VideoPatch running?

No, the patch is applied to the video editor's files directly. You only need to run VideoPatch once to apply the patch (and again if the editor updates).

### Does it work on 32-bit systems or Mac?

No, VideoPatch is a Windows-only utility designed for 64-bit versions of Windows 10 and 11.
